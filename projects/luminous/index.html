Luminous — AI Video Editor

An agent-accessible video editing platform that turns media analysis and editing plans into rendered short-form video.

Architecture

Luminous combines a Python Flask API with a React and Remotion studio, asynchronous media-processing workers, PostgreSQL-backed application data, and an FFmpeg rendering pipeline. Its workflow moves through ingesting assets, analyzing video and audio, generating an edit plan, adjusting the timeline, and rendering the result.

AI agents and observability

The platform exposes structured video-editing operations through an MCP server. Azure OpenAI supports AI-assisted planning, while Langfuse provides tracing and evaluation to diagnose failures and compare outputs.

Supporting engines

Retime Engine handles temporal video effects and retiming; Beattime Engine provides beat and tempo signals for music-synchronized edits; Visual Analysis Engine supplies scene and visual content understanding. Each is developed as a supporting component of Luminous.

Technology

Python · Flask · React · Remotion · FFmpeg · PostgreSQL · MCP · Langfuse · Azure OpenAI
